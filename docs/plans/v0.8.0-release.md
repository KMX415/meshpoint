# v0.8.0 release overview

This branch contains unreleased work for RC testing. Stable remains unchanged.

## Included features

- Optional plugin store with individual installation, dependency information,
  explicit enablement, updates and removal. Optional apps are not preinstalled
  or enabled by an ordinary Meshpoint update.
- Theme selection, custom palettes and shared styling for optional pages.
- Reticulum and LXMF messaging with separately installed dependencies,
  isolated processes and explicitly configured network or RNode interfaces.
- Experimental Radio, DAB+, ACARS, ADS-B, RTL433 and pager adapters.
- Read-only Viewer access and optional public dashboard summaries.
- Backup validation, USB access improvements and clearer reconnect handling.
- Packet-count node sorting and Stats display-unit fixes.

See the [changelog](../CHANGELOG.md), [plugin guide](../PLUGINS.md),
[Reticulum guide](../../apps/reticulum/README.md) and
[dashboard access guide](../DASHBOARD-ACCESS.md) for behavior and setup.

## RC limitations

Automated regression checks and scoped device tests have passed. This does
not establish compatibility with every radio, operating system or plugin.

- Published-catalog install and update testing remains required.
- Native SDR receiver dependencies, decoding, audio and performance still
  require hardware testing. P25 is experimental and has not passed native
  receiver validation. DAPNET is unfinished; Flock detection is not implemented.
- Reticulum bidirectional RNode messaging and USB reconnect have been tested.
  Full power-cycle recovery, endurance and external-network interoperability
  remain open checks. Regional profiles are starting points, not certifications.
- Fresh-install and upgrade coverage, optional feature combinations and
  access-control checks on devices remain part of RC testing.

Keep core Meshtastic and MeshCore functionality in the regression scope when
adding optional apps. Report the version, hardware, reproduction steps and
sanitized errors when submitting an issue.
