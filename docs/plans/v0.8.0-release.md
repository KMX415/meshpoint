# v0.8.0 release overview

## Included features

- Optional plugin store with pinned sources, individual downloads, dependency
  reporting, enablement, replacement and removal. Apps install disabled and
  native receiver packages are not installed by an ordinary core update.
- Themes, custom palettes, read-only Viewer access and opt-in public summaries.
- Reticulum/LXMF with separately installed dependencies and isolated workers.
- MeshCore contact positions, channel heard-repeat paths and DM acknowledgements.
- Registered-pin Approximate/Hidden privacy, received coding-rate display,
  terminal EOF cleanup, USB permissions and reconnect/restore hardening.
- Packet-count node sorting, Stats units, companion flashing and hardware guides.

See [changelog](../CHANGELOG.md), [plugin guide](../PLUGINS.md),
[Reticulum guide](../../apps/reticulum/README.md) and
[dashboard access](../DASHBOARD-ACCESS.md).

## Upgrading

Use **Settings > Updates > Stable > Apply** after the release is available,
or follow the [installer-based update instructions](../../README.md#updating).
Back up configuration and data first. The installer updates dependencies and
runs migration hooks; a bare Git pull and service restart can miss these steps.

Optional apps are not installed or enabled automatically. Source downloads and
Web Terminal access remain opt-in. See the [plugin guide](../PLUGINS.md) and
[dashboard access guide](../DASHBOARD-ACCESS.md) for setup and permissions.

## Known limitations

- SDR adapters, P25 and PiMesh remain experimental. Check hardware and native
  dependency requirements before enabling them.
- Reticulum cold-start, long-running reliability and interoperability with
  external networks need further validation.
- Plugin compatibility across versions and native receiver support vary by app.
  Follow each app's setup and update instructions.
- DAPNET and Flock are not supported in this release.
- Community hardware guides apply to the board and OS image described; they
  do not imply support for every hardware revision.
