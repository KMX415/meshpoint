    Plugin sources Choose where your modules come from

    Enable downloads on the device first

    This permission cannot be changed from the dashboard. Ask the device owner to complete these steps, or use SSH if you manage this Meshpoint.

    1. Edit /opt/meshpoint/config/local.yaml on the device. Add or update the top-level setting below, outside any other section:
      plugin_sources_enabled: true
    2. Save the file, then restart Meshpoint:
      sudo systemctl restart meshpoint
      Capture briefly pauses during the restart.
    3. Reload this page. The source fields will unlock. Review the catalog below, confirm that you trust it, then select Add source.

    Your existing mesh features and installed modules do not need this permission. Enabling downloads does not install anything automatically.

    Add a trusted GitHub catalog to install modules. Each download uses the revision shown below.

    Themes

    Default theme

    The default for browsers without a saved theme preference. Your browser preference takes priority.

    Theme builder

    Changes preview across the dashboard. Leaving this page restores your previous appearance. Choose Save to device to keep a theme.

    The Messages panel and Terminal keep their own colour sets (--msg-* / --term-*) : you can't preview them from here, so they aren't swatches.     Save keeps the theme on this device. Reload to use a newly saved theme. Download a copy to share it.

    Installed themes

    Manage themes saved on this device. Built-in themes are always available.

    Authentication

    Manage admin credentials, sessions, the viewer role, and lockout policy.

    Change password

    Rotates this account's password and invalidates other browser sessions immediately.

    Sign out everywhere

    Invalidates every outstanding session, including this one. You'll be redirected to /login.

    Viewer role Disabled

    Read-only login for sharing the dashboard with trusted observers. Viewers cannot reach Settings or the Terminal.

    Public view

    Off by default. When enabled, anyone who can reach this dashboard can see the selected summaries without signing in. Messages, node locations and other configuration stay private.

    Pages to share

    Failed-login lockout

    After this many failures, login is blocked for the cooldown window. Defaults to 5 attempts / 5 minutes.

    Session lifetime

    How long a fresh login stays valid before the dashboard bounces you back to /login. Pick a preset or set custom minutes (5 min – 30 days). Existing sessions keep their original expiry until they run out.

    Equivalent 8 hours

    Backup and restore

    Download a timestamped archive of config/local.yaml and the full data/ directory (SQLite snapshot, PKI keys, rollback state). The file contains all secrets. Store it offline. Do not commit it to git or email it.

    Service actions
